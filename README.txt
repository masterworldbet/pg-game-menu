วิธีใช้งาน
1. อัปโหลด index.html, games.json และโฟลเดอร์ images ขึ้น Hosting ให้อยู่ระดับเดียวกัน
2. เปิด games.json แล้วเปลี่ยน url ของแต่ละเกมเป็นลิงก์ปลายทางจริง
3. เปลี่ยน name และ popularity ได้ตามต้องการ
4. เปิด index.html ผ่านโดเมน จะใช้งานบนมือถือ/LINE Browser ได้

หมายเหตุ: popularity ในไฟล์เริ่มต้นเป็นตัวอย่าง ไม่ใช่โอกาสชนะหรือผลตอบแทน
